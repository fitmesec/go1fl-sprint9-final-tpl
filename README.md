# Поиск максимального значения в большом массиве данных

Учебный проект на тему «Многопоточность» в Go. Программа находит максимальное значение в слайсе целых положительных чисел двумя способами — в один поток и в несколько потоков (горутин) — и сравнивает время выполнения.

## Описание

Программа генерирует слайс из `SIZE` случайных положительных чисел, а затем ищет максимальное значение в нём двумя способами:

1. **В один поток** — функция `maximum()` проходит по всему слайсу последовательно.
2. **В несколько потоков** — функция `maxChunks()` делит слайс на `CHUNKS` равных частей, в каждой части ищет максимум параллельно (в отдельной горутине), а затем находит максимум среди всех найденных значений.

Время выполнения каждого способа измеряется в микросекундах и выводится в консоль для сравнения.

## Функции

- `generateRandomElements(size int) []int` — генерирует слайс из `size` случайных положительных чисел.
- `maximum(data []int) int` — находит максимальное значение в слайсе (однопоточный вариант).
- `maxChunks(data []int) int` — находит максимальное значение в слайсе, разделяя его на части и обрабатывая их параллельно в горутинах.

## Пример результата:

Генерируем 100000000 целых чисел
Ищем максимальное значение в один поток
Максимальное значение элемента: 100000000
Время поиска: 100358 мкс
Ищем максимальное значение в 8 потоков
Максимальное значение элемента: 100000000
Время поиска: 14990 мкс


| Способ | Время поиска |
|---|---|
| В один поток | 100358 мкс |
| В 8 потоков | 14990 мкс |

> Как видно из результата, поиск максимума в **8 потоков оказался почти в 6.7 раза быстрее**, чем в один поток — это наглядно демонстрирует эффективность использования многопоточности при обработке больших массивов данных.
